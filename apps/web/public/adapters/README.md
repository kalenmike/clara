# Adapter registry

The hub reads:

```
/adapters/<harness>/manifest.json
```

and runs the install script it names:

```
/adapters/<harness>/v<version>-install.sh
```

The adapter archives live on GitHub Releases (or another HTTPS host); the
manifest contains their absolute URLs. This folder only carries the small
manifest and install script, which are generated by `pnpm adapters:build`.

See `tools/adapters/README.md` for the release steps.
